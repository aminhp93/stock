# Prompts & Session History Directory

Thư mục này lưu trữ nhật ký, lịch sử các yêu cầu (prompts) và ghi chú kỹ thuật qua các phiên làm việc (sessions) phát triển dự án.

## Cấu trúc đặt tên file:
- `NN_<chu_de>.md` (Ví dụ: `01_vite_rewrite.md`, `02_backtest_improvements.md`)

## Danh sách các phiên làm việc:
- [01_vite_rewrite.md](./01_vite_rewrite.md): Viết lại toàn bộ ứng dụng sang Vite + React (TypeScript) với 3 trang (`/`, `/chart`, `/dashboard`), Minimalist Light Theme và xóa bỏ legacy code `dashboard/`.
